# 🏥 Healthcare Patient Analytics & Cost Optimization Dashboard

## 📌 Project Overview
This end-to-end analytics project digs into patient records, hospital performance, and billing behavior to uncover insights that support smarter decisions in healthcare. It brings together Python, SQL, and Power BI across the full pipeline — from raw data to a finished dashboard.

---

## 🎯 Objectives
- Study admission patterns and patient demographics
- Assess how hospitals and doctors are performing
- Break down billing behavior and cost distribution
- Evaluate cost efficiency against length of stay
- Present findings through an interactive dashboard

---

## 🛠️ Tools & Technologies
- **Python** (Pandas, NumPy, Matplotlib, Seaborn)
- **SQL (PostgreSQL)**
- **Power BI**

---

## 🐍 Python (EDA)
Exploratory analysis was used to:
- Clean the dataset and fix inconsistencies
- Address missing values and duplicate entries
- Examine distributions and relationships between variables
- Surface trends, patterns, and outliers in the data

---

## 🗄️ SQL Analysis
SQL was applied to:
- Aggregate and group data for summary views
- Surface top-performing hospitals and high-cost patients
- Track revenue and billing trends over time
- Use window functions for ranking and deeper insights

---

## 📊 Power BI Dashboard
Built a multi-page, interactive dashboard covering:

- **Executive Summary**
- **Medical Condition Analysis**
- **Billing & Insurance Analysis**
- **Doctor & Hospital Performance**
- **Cost Efficiency Analysis**

Features:
- KPI cards (Total Patients, Total Billing, Avg. Length of Stay, Cost per Day)
- Interactive filters and slicers
- Trend comparisons and performance breakdowns

---

## 🔍 Key Insights
- Admission types are fairly balanced across the dataset
- Billing amounts show wide variation, with a handful of high-cost outliers
- Age, billing, and length of stay show only a weak correlation with each other
- Patient volume is concentrated among a small set of hospitals
- Cost efficiency shifts noticeably depending on the medical condition

---

## 📈 Conclusion
This project shows how healthcare data, once properly cleaned and analyzed, can be turned into insights that actually drive decisions. It underscores why data-driven approaches matter for improving efficiency and controlling costs in healthcare settings.
